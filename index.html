Projects

Go

Distributed Job Queue

Go · PostgreSQL · Docker

GitHub ↗

An HTTP API for typed background jobs and independently deployed Go workers. PostgreSQL is the only coordination point. Workers claim jobs with SELECT … FOR UPDATE SKIP LOCKED and hold a time-bound lease with a fencing token. If a worker is killed mid-job, another worker reclaims and finishes it.

  • At-least-once delivery
  • Leases + fencing tokens: a stale worker’s acknowledgement is rejected
  • Retries with exponential backoff, then dead letter
  • Integration test: 200 jobs × 12 concurrent claimers, zero duplicates
Java

DAG Orchestrator

Java 21 · Spring Boot 3.3 · PostgreSQL · React Flow

GitHub ↗

A workflow service that accepts declarative DAG definitions and validates the dependency graph. It runs independent steps concurrently while respecting prerequisites, and the UI shows every node’s status live as the run executes. Single-node: one JVM runs the API, scheduler and a bounded executor.

  • Validation: Kahn topological sort, structured 422 errors for cycles and bad dependencies
  • Retries with exponential backoff (2 s → 4 s → 8 s, capped at 60 s)
  • Fail-fast: after a terminal failure, not-yet-started tasks are skipped
  • Restart recovery: tasks left running by a dead process are retried
C++

Mini SQL Engine

C++20 · CMake · Docker

GitHub ↗

A small in-memory relational query engine written from scratch. It loads typed CSV tables, parses a documented SQL subset, builds an execution plan, runs it, and can use single-column hash indexes for equality lookups. EXPLAIN shows which access path was chosen.
